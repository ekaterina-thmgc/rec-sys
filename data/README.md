# Данные

В рамках прототипа используется синтетический датасет, имитирующий структуру открытых наборов KION (МТС) и Yambda (Яндекс Музыка).

**Структура:**
- `user_id` — идентификатор пользователя
- `item_id` — идентификатор объекта (фильм/трек)
- `item_category` — категория объекта
- `timestamp` — время события
- `event_type` — тип события (view/click/purchase)

**Масштаб:** 5000 событий, 100 пользователей, 500 объектов.

Для воспроизведения на полноразмерных данных достаточно заменить блок генерации на загрузку сэмпла из оригинального датасета (см. раздел "Направления дальнейшей работы" в отчёте).
