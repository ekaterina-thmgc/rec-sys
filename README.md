# Автоматическая генерация признаков для рекомендательных систем с помощью LLM-агента

Решение исследовательского задания Лаборатории Т-Банка.

## О задаче
Исследуется возможность автоматизации построения признаков для рекомендательных систем с использованием LLM-агента вместо ручного feature engineering.

## Структура проекта
- `code/solution.py` — воспроизводимый пайплайн (генерация данных, baseline, LLM-признаки, сравнение)
- `data/` — описание данных
- `reports/report.md` — подробный отчёт с методологией, результатами и выводами
- `reports/results.json` — метрики экспериментов

## Запуск
```bash
pip install -r requirements.txt
python code/solution.py
